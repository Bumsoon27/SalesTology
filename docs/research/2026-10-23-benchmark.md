### AI 디렉션 규칙 (src/features/deals/direction.ts)

우선순위 순: 열린 이슈(100) → 기한 지남(85~95) → 정체(50+일수, 최대 80) → 임박 D-3(67~70) → 수주 후 배송·계산서 일정 없음(60) → GP율 5% 미만(55) → **단일 접점(52)** → 규모·GP 빈칸(40~45) → 단계별 플레이북(30).

### 단일 접점 (Clari single-threading)

- 대상: 규모 **1억 이상**, 수주 전 단계, 최근 **90일** 안에 활동 기록이 있는 사업
- 활동 기록의 **'누구와'(고객 쪽 상대)** 가 0~1명이면 경고 — 1명: "다른 담당자도 만나기 — 지금은 김과장 한 명", 0명: "'누구와' 남기기"
- 이름은 공백·대소문자를 무시하고 같은 사람으로 본다. 활동 기록이 아예 없으면 '정체' 신호가 다룬다

### 관계 강도 (Affinity relationship strength) — src/features/deals/relationship.ts

- 회사마다 내 사업의 상호작용을 모은다: 미팅 1.5 · 통화 1.2 · 메일 1 · 메모 0.8 · 업무 완료 1 · 사업 활동 0.5
- 최근일수록 크게: 무게 × e^(−경과일/30), 1년 넘은 기록은 제외
- 점수 = 100 × (1 − e^(−합/2)) → **강함 70+ / 보통 40+ / 약함 15+ / 소원**
- 사업의 상호작용은 그 사업의 고객사와 SI·매입처 모두에 반영된다
- 우주 그래프: 회사 노드의 크기·밝기에 40% 섞는다 (금액·참여 수 60%). 회사 노드를 누르면 점수·등급·마지막 상호작용이 보인다
제안마다 **근거(why)** 를 함께 보여준다. 급한 신호가 없으면 대시보드 [오늘 할 일]은 규모 큰 사업의 단계 플레이북으로 채운다.

### AI 코칭 켜는 법

지금은 모델 설정이 없어 **규칙 기반**으로 동작한다 (같은 형식의 진단·방향·할 일). Vercel → Settings → Environment Variables (Production) 에 넣으면 다음 배포부터 sLLM 으로 바뀐다.

| 방식 | 넣을 값 |
|---|---|
| 사내/자체 sLLM (권장) — vLLM·Ollama·LM Studio 등 OpenAI 호환 API | `AI_COACH_PROVIDER=openai`, `AI_COACH_BASE_URL=https://…/v1` (https 만), `AI_COACH_MODEL=모델이름`, 필요하면 `AI_COACH_API_KEY` |
| Gemini | `AI_COACH_PROVIDER=gemini`, `GEMINI_API_KEY` (SOS 와 같은 키), 선택 `AI_COACH_MODEL` |

- 부문별 끄기: 관리자 화면 → 파이프라인 설정 → 'AI 코칭 사용'
- 사용자별 하루 30회, 같은 사업·같은 신호는 캐시 (`deal_coaching`)
- 화면의 **'모델에 보내는 정보 보기'** 로 실제 전송 내용을 확인할 수 있다

## sLLM 보안 설계 (#66 에 그대로 구현)

AI 디렉션은 **규칙 기반**이라 사업 데이터가 외부로 나가지 않는다. AI 코칭(sLLM)은 아래 원칙으로 붙였다.

1. **입력은 원문이 아니라 신호**: `suggestDirections` 결과(종류·우선순위·일수)와 단계·금액 구간만 보낸다. 고객사명·담당자명·메모 본문은 보내지 않는다 (필요하면 `고객A` 처럼 가명 처리).
2. **모델 위치**: 가능하면 사내/자체 호스팅 sLLM(예: Ollama 등 로컬 실행)으로 서버에서만 호출. 외부 API(Gemini 등)를 쓰면 `server-only` 모듈에서만, 키는 Vercel 환경변수(`NEXT_PUBLIC_` 금지), 부문 관리자가 켜고 끄는 설정으로.
3. **출력 검증**: 모델 출력은 텍스트로만 렌더링(HTML 해석 없음), 길이 제한, 실패·지연 시 규칙 기반 결과를 그대로 보여준다.
4. **비용·남용 방지**: 사용자별·하루 호출 상한, 같은 사업은 활동이 바뀔 때만 다시 생성(캐시).
5. **기록**: 무엇을 보냈는지 로그(본문 제외)를 남겨 감사 가능하게.
