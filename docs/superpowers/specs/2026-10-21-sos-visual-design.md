# SOS 시각 디자인 (B 영역 전용)

- 작성일: 2026-10-21
- 상태: **DJ 승인 (2026-10-21)** — SB 리뷰 대기
- 관련: SOS 설계서 `2026-10-20-sos-design.md` §5
- 참고 원본: `references/sos-visual-reference-remember.md` (DJ 제공. 리멤버 웹의 시각 언어를 정리한 카탈로그 문서)

표기: **[DJ]** = DJ가 정한 것, **[제안]** = 설계자가 정한 것으로 DJ 확인 대상, **[빌더]** = 구현자가 정해도 되는 것.

---

## 1. 원칙

1. **SOS 화면에만 적용한다.** [DJ] `src/app/sos/` 아래만 바뀐다. SalesTology(A) 화면과 공용 `AppHeader`·`src/shared/ui` 는 건드리지 않는다.
2. **다크가 기본이다.** [DJ] A의 블랙 테마와 탭을 오갈 때 밝기가 튀지 않게 한다. 라이트 모드는 지금 만들지 않는다(토큰 이름만 맞춰 두어 나중에 추가 가능).
3. **무채색 화면 + 오렌지 한 점.** 표면과 글자는 흑백 램프로 덮고, 브랜드 오렌지는 강조·하이라이트·진행 표시에만 쓴다. 오렌지를 버튼 채움으로 쓰지 않는다.
4. **얕은 모서리, 선으로 나누는 깊이.** 모서리 4~6px, 그림자보다 구분선.
5. **시각 처리만 가져온다.** 리멤버의 로고·이름·문구·제품 개념(명함·채용 흐름)은 쓰지 않는다. SOS 화면 어디에도 "리멤버"가 나오지 않는다.

네임스페이스는 `--sos-*` [제안]. 원본의 `--rui-*` 를 쓰지 않는다.

### 2.2 액센트 (테마 불변)
| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--sos-accent` | `#FF8F6B` | 일치 키워드 하이라이트(`mark`), 링크·hover 글자, 현재 단계 점, 수집 진행 막대와 그 빛 |
| `--sos-accent-bg` | `#33201A` | 하이라이트된 키워드 칩의 연한 바탕 |

원본의 주황 `#FF6A0D` 대신 채도를 낮춘 코랄을 쓴다(2026-10-23 DJ 결정, SB #39 리뷰 반영). SOS 화면에서도 공용 상단 바는 앱 강조색 보라(`--accent` `#9AABFF`)로 보이므로, 따뜻한 SOS 정체성은 남기되 보라와 부딪히지 않게 했다. `--sos-bg-surface`(`#1A1A1A`) 위 대비 7.8:1, `--sos-accent-bg` 위 6.9:1.

| 토큰 | 값 | SOS 쓰임 |
|---|---|---|
| `--sos-red` / `--sos-red-bg` | `#EB3838` / `#521D1D` | 마감 D-3 이내, 수집 실패, 제외 키워드 칩 |
| `--sos-yellow` / `--sos-yellow-bg` | `#D1AD36` / `#383015` | 마감 D-7 이내, 일부 출처 실패(`partial`), "키워드 불일치"·"기관 확인 필요" |

| `--sos-blue` / `--sos-blue-bg` | `#418AF0` / `#002861` | 정보성 표시: 기존 고객, 예측(`predicted`) 리드 |
| `--sos-ai` / `--sos-ai-bg` | `#A770FF` / `#291E3C` | "AI 요약" 표시, AI 요약 문장 블록 |

## 3. 글꼴과 글자 크기
- 글꼴: 앱 공통 **나눔스퀘어라운드** (`var(--font-nanum-round)`, 루트 layout 이 `next/font/local` 로 불러온다). 스택은 `src/app/globals.css` 의 `body` 와 같다: `var(--font-nanum-round), "Pretendard", "Apple SD Gothic Neo", "Malgun Gothic", sans-serif`
- 불러오기: SOS 가 따로 불러오지 않는다(별도 CDN `<link>` 없음). 2026-10-23 SB #39 리뷰에 따라 Pretendard 에서 바꿨다.
- 크기 단계: 12 · 14 · 16 · 18 · 20px (원본 현행 관측 다섯 단계). 행간 기본 1.45.
- 굵기: 400(기본) · 600. 나눔스퀘어라운드에는 400·700·800 만 있어 500은 400으로, 600은 700으로 보인다. 아래 표의 600은 실제로 700(Bold)으로 그려진다.
- 숫자(예산·D-n·점수)는 `font-variant-numeric: tabular-nums` [제안].

| 자리 | 크기 / 굵기 / 색 |
|---|---|
| 페이지 제목 | 20 / 600 / `--sos-text-strong` |
| 섹션 헤딩 | 20 / 600 / `--sos-text` |
| **리드 카드 영업기회 요약** | 18 / 600 / `--sos-text-strong`, 행간 1.45 |
| 핵심 숫자 4칸의 값 | 18 / 600 / `--sos-text-strong` |
| 카드 제목·리스트 항목 | 16 / 400 / `--sos-text-strong` |
| 본문·근거 시그널 | 14 / 400 / `--sos-text` |
| 메타(출처·날짜)·칸 이름 | 12 / 500 / `--sos-text-sub` |

## 4. 간격·모서리·깊이·움직임
- 간격 단계: 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48px. 요소 사이는 잘게(4~12), 표면 안쪽은 넓게(16~24).
- 카드 안쪽 여백 20px, 카드 사이 12px, 섹션 사이 32px [제안].
- 모서리: 기본 4px(입력창·필터·작은 표면), **6px(버튼·칩·카드·토스트)**, 알약 30px(상단 보기 전환 `[사업별 | 기관별]` 선택 필만). 원형은 아바타(담당자)만.
- 깊이: 다크에서는 그림자 대신 **1px 선**(`--sos-divider`)과 표면 단계(`page` → `surface` → `modal`)로 나눈다. 모달·팝오버만 `0 0 16px rgba(0,0,0,.2)` 수준의 그림자 [제안].
- 움직임: hover 200ms `ease-in-out`, 패널·모달 열기 450ms `cubic-bezier(.165,.84,.44,1)`. `prefers-reduced-motion` 이면 끈다. 오버슈트 곡선은 쓰지 않는다 [제안].

## 5. SOS 컴포넌트

### 5.1 버튼
| 종류 | 모양 | SOS 쓰임 |
|---|---|---|
| 주 버튼 | **흰 채움** `#FFFFFF` + 검정 글자, 높이 40px, 좌우 16px, 6px | [수집 시작], [사업으로 전환] — 화면당 하나만 |
| 보조 버튼 | 채움 없음 + `--sos-divider` 테두리 + `--sos-text` 글자, 높이 32px, 좌우 12px, 6px | 담당 지정, 보류, 관심 없음, [재분석], [합치기] |
| 텍스트 버튼 | 글자만, hover 시 `--sos-accent` | 원문 링크, "더 보기" |
| 위험 버튼 | 보조 버튼 + `--sos-red` 글자 | 키워드 삭제 확인 |

32px 버튼은 터치 영역이 작으므로 의사요소·패딩으로 **누르는 영역을 44×44px 이상**으로 넓힌다 [제안].

[수집 시작]이 실행 중이면 비활성(`--sos-disabled`) + "수집 중…" 글자, 버튼 아래에 진행 막대.

### 5.2 수집 진행 막대
높이 2px, `--sos-accent` 선 + 같은 색 빛(`0 0 10px`, `0 0 5px`). 출처별 줄에는 상태 글자(대기·진행·완료 n건·실패 사유)를 함께 쓴다.

### 5.3 리드 카드
- 표면 `--sos-bg-surface`, 1px `--sos-divider`, 6px, 안쪽 20px.
- 맨 위 **영업기회 요약 블록**: AI 요약이면 왼쪽 4px `--sos-ai-gradient` 띠 + 오른쪽 위 "AI 요약" 작은 표시(`--sos-ai` 글자, `--sos-ai-bg` 바탕, 4px). 템플릿 요약이면 띠 없이 "기본 요약" 표시(`--sos-text-hint`).
- 핵심 숫자 4칸: 칸 이름 12/500 `--sos-text-sub`, 값 18/600. 다음 마감 값은 D-3 이내 `--sos-red`, D-7 이내 `--sos-yellow`.
- 단계 막대: 지난 단계 `--sos-text`, 현재 단계 `--sos-accent` 점 + 글자, 남은 단계 `--sos-text-hint`. 칸 사이 1px 선.
- 제목 속 **일치 키워드는 `--sos-accent` 글자로 하이라이트**(`mark`, 바탕 없음). 드래그 선택 시 나오는 "+ 핵심 / + 확장 / − 제외" 작은 메뉴는 `--sos-bg-modal`.
- 상태 표시(오른쪽 위 작은 글자): 기존 고객 `--sos-blue`, 새 진행 `--sos-yellow` + 행 바탕 `--sos-bg-highlight`, 키워드 불일치 `--sos-yellow`, 전환됨 `--sos-green`.
- 점수: 숫자만 16/600 `--sos-text-strong`. 점수에 색을 입히지 않는다(점수는 위험이 아니다) [제안].

### 5.4 키워드 칩 (`/sos/settings`)
높이 32px(누르는 영역 44px), 좌우 12px, 6px, 14/500.
| 칸 | 모양 |
|---|---|
| 핵심 | 흰 채움 `#FFFFFF` + 검정 글자 |
| 확장 | 채움 없음 + `--sos-divider` 테두리 + `--sos-text-sub` 글자 |
| 제외 | `--sos-red-bg` 바탕 + `--sos-red` 글자 |
| 꺼짐 | 위 모양 + 글자 `--sos-text-hint`, 취소선 없음 |

입력창: `--sos-bg-input`, 1px `--sos-divider`, 4px, 높이 44px, placeholder `--sos-text-hint` — "키워드 입력 후 Enter (쉼표로 여러 개)". 칸 선택 `[핵심 ▾]` 은 입력창 오른쪽.

### 5.5 목록·보기 전환·필터
- `[사업별 | 기관별]`: 알약 30px, 선택된 쪽 흰 채움 + 검정 글자, 나머지 글자만.
- 탭(사업 리드 / 이슈 시그널 / 기관 확인 필요): 글자 탭, 선택 시 흰 글자 + 아래 2px 흰 선, 나머지 `--sos-text-sub`.
- 필터 버튼: 높이 40px, 4px, `--sos-bg-surface` + 1px 선.
- 기관별 보기의 기관 행: 1px 아래 선(`--sos-divider-lite`), 펼치면 카드가 안쪽 16px 들여쓰기.

### 5.6 토스트·빈 상태
- 토스트: `--sos-bg-modal`, 6px, 안쪽 14px 24px, 최소 폭 320px. 오류는 왼쪽 4px `--sos-red` 띠.
- 빈 상태: 가운데 `--sos-text-sub` 14px "아직 수집한 기록이 없습니다. [수집 시작]을 눌러 보세요" + 주 버튼.

## 6. 반응형
- 중단점: **768px**, **1000px** (원본 발행값).
- ≤767px: 카드 한 줄, 핵심 숫자 4칸 → 2×2, 필터는 아래에서 올라오는 시트, 좌우 여백 16px, 페이지 가로 스크롤 없음.
- 768~999px: 카드 한 줄(넓게), 필터는 상단 가로 줄.
- ≥1000px: 목록 + 오른쪽 상세 패널(카드 클릭 시), 좌우 여백 24px, 최대 폭 1280px [제안].

## 7. 구현 방식 [제안]
- `src/app/sos/layout.tsx` 가 `AppHeader` 아래 SOS 영역을 `<div className="sos-theme">` 로 감싼다.
- `src/app/sos/sos-theme.css` 에 `.sos-theme { --sos-*: … }` 와 바탕·글꼴을 선언하고, 이 레이아웃에서만 import 한다. 전역 `globals.css` 와 Tailwind `@theme` 은 건드리지 않는다.
- 컴포넌트는 Tailwind 임의값으로 변수를 참조한다(예: `bg-[var(--sos-bg-surface)]`). [빌더] 반복이 많으면 `src/features/sos/ui/` 에 작은 래퍼 컴포넌트로 묶는다.
- 아이콘: 직선·각진 형태(모서리 radius 0)의 선 아이콘. [빌더] 라이브러리를 추가하려면 공용 변경이므로 SVG를 `src/features/sos/ui/icons/` 에 직접 둔다.

## 8. 하지 않는 것
- 오렌지 채움 버튼, 오렌지 면(넓은 바탕).
- 리멤버 로고·이름·슬로건·문구 사용.
- A 화면·공용 헤더의 색 변경.
- 라이트 모드(이번 범위 밖).
